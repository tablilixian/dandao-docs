# 一、典籍简介

## 1.1 基本信息

| 项目 | 内容 |
|------|------|
| **全称** | 《太乙金华宗旨》或《金华宗旨》 |
| **别名** | 《太上金华宗旨》 |
| **托名作者** | 吕洞宾（纯阳真人） |
| **实际成书** | 清代（具体不详） |
| **传授方式** | 扶鸾（扶乩）传授 |
| **篇章结构** | 共13章 |

## 1.2 特点

1. **直提性功**：不落第二法门，直接讲性功修炼
2. **简明易懂**：比《灵宝毕法》更通俗易懂
3. **重在回光**：以"回光"为核心修炼方法
4. **东西合璧**：西方心理学家荣格曾为此书作注

## 1.3 核心概念

| 概念 | 含义 |
|------|------|
| **金华（光）** | 先天太乙之真气，人之元神 |
| **天心** | 祖窍、玄关、寸田尺宅 |
| **回光** | 凝神聚光，返还先天 |
| **金华乍吐** | 回光初验，金光显现 |
| **坎离** | 阴阳、心肾、性命 |
| **周天** | 坎离交媾，真气运行 |

## 1.4 与其他经典的关系

### 与《灵宝毕法》的关系

| 项目 | 灵宝毕法 | 太乙金华宗旨 |
|------|----------|--------------|
| **核心理念** | 性命双修 | 性功为主 |
| **修炼次第** | 三乘十门 | 回光为本 |
| **最终目标** | 金丹成就 | 天心正位 |
| **理论基础** | 精气神 | 光 |
| **侧重点** | 命功详细 | 性功详细 |
| **表述风格** | 古奥繁复 | 简明易懂 |

### 学习建议

1. **入门**：先读《太乙金华宗旨》建立概念
2. **深入**：再读《灵宝毕法》系统学习
3. **实修**：以《太乙金华宗旨》方法为主
4. **验证**：参考《灵宝毕法》证验标准
