# 附录一：历代注释要点

## 一、卫礼贤注释

### 1. 人物简介

| 项目 | 内容 |
|------|------|
| **姓名** | 理查德·威廉（Richard Wilhelm） |
| **中文名** | 卫礼贤 |
| **国籍** | 德国 |
| **生卒** | 1870-1930年 |
| **身份** | 汉学家、传教士 |
| **主要贡献** | 将《太乙金华宗旨》译为德文 |

### 2. 翻译背景

- **译本名称**：《中国养生秘笈》或《金花的秘密》
- **出版时间**：1928年
- **合作者**：与荣格合作撰写注释

### 3. 主要观点

| 观点 | 说明 |
|------|------|
| **金华象征** | 金华象征人的心灵能量 |
| **回光是核心** | 回光是东方冥想的核心方法 |
| **东西对话** | 与西方心理学有相通之处 |
| **实践价值** | 具有实际的心灵修炼价值 |

## 二、荣格评注

### 1. 人物简介

| 项目 | 内容 |
|------|------|
| **姓名** | 卡尔·古斯塔夫·荣格（C.G. Jung） |
| **国籍** | 瑞士 |
| **生卒** | 1875-1961年 |
| **身份** | 心理学家、分析心理学创始人 |
| **主要贡献** | 为《金花的秘密》撰写长序 |

### 2. 主要观点

#### 2.1 光与心灵能量

| 观点 | 说明 |
|------|------|
| **金华即光** | 金华象征人的生命能量（Libido） |
| **自体发光** | 光=心理能量的自体发光 |
| **能量转化** | 回光是能量向内转化的过程 |

#### 2.2 自性原型

| 观点 | 说明 |
|------|------|
| **曼陀罗图案** | 金华显现如曼陀罗图案 |
| **自性原型** | 对应心理学中的"自性原型"（Self） |
| **整合象征** | 曼陀罗是心灵整合的象征 |

#### 2.3 东西方心理

| 观点 | 说明 |
|------|------|
| **相互印证** | 东方修炼与西方心理学可相互印证 |
| **潜意识整合** | 内丹修炼是潜意识整合的过程 |
| **无意识研究** | 与弗洛伊德分道扬镳，转向无意识研究 |

### 3. 荣格原文摘录

> "《太乙金华宗旨》中道家修炼的目的是将人内在的两个半球合二为一：一个是表现为意志的、积极的、能动的'意识'半球，另一个则是被动的、潜藏的、灵性的'潜意识'半球。"
