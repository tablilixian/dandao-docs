## 学习指引

### 入门顺序
1. 先读 `01_典籍简介.md` 了解全书概貌
2. 再读 `04_核心理论.md` 掌握核心概念
3. 按章节顺序阅读 13 章详解
4. 参考附录内容深化理解

### 修炼建议
1. 入门：先读《太乙金华宗旨》建立概念
2. 深入：再读《灵宝毕法》系统学习
3. 实修：以本书方法为主
4. 验证：参考证验标准
