# 二、成书背景

## 2.1 传授记录

根据《吕祖全书》记载：

> "壬申孟夏旬有四日，值纯阳圣祖证道之辰，宇庵先生偕真斋沐朝礼，礼竟，辄为扶鸾之举，真佐焉。翼日，真庵潘子适至，伏蒙圣祖首录余二人，命宇庵先生为本师。至五月六日，于古红梅阁徧礼诸真，始得授太乙金华宗旨。"

## 2.2 扶鸾背景

### 什么是扶鸾（扶乩）

- **定义**：古代一种请神降笔的仪式
- **方法**：道士用法术请神仙降临，由人扶着鸾笔书写
- **目的**：通过这种仪式，神仙将修炼秘诀传授给信道者
- **结果**：《太乙金华宗旨》即通过此法传授

### 扶鸾的历史

| 时期 | 情况 |
|------|------|
| 起源 | 古代道教仪式 |
| 发展 | 历代道教常用 |
| 清代 | 《太乙金华宗旨》等典籍通过此法传授 |
| 现代 | 部分道教团体仍有使用 |

## 2.3 历史地位

| 地位 | 说明 |
|------|------|
| **道教经典** | 道教内丹术的重要典籍 |
| **内丹指南** | 与《灵宝毕法》互为补充 |
| **西方影响** | 被译介至西方，影响深远 |
| **学术价值** | 荣格评价："是世界上最重要的心理学著作之一" |

## 2.4 西方传播

### 卫礼贤译本

- **译者**：德国汉学家卫礼贤（Richard Wilhelm）
- **译本**：德文版《中国养生秘笈》（1928年）
- **副标题**：《金花的秘密》

### 荣格评注

- **评注者**：瑞士心理学家卡尔·荣格（C.G. Jung）
- **评注内容**：为卫礼贤译本撰写长序和评论
- **意义**：将东方内丹修炼与西方分析心理学相结合

### 荣格评价

> "《太乙金华宗旨》是世界上最重要的心理学著作之一。"

荣格认为此书揭示了人类心灵的秘密，是东方与西方心理学对话的桥梁。
