## 一、核心思路

> **"行住坐卧皆可修"**——《太乙金华宗旨》

### 1.1 三大原则

| 原则 | 说明 |
|------|------|
| **融入日常** | 不追求专门时间，把修炼融入通勤、工作、休息 |
| **短时高频** | 不求单次时长，贵在频繁坚持 |
| **动静结合** | 静坐（静功）+ 散步/八段锦（动功） |

### 1.2 修炼体系

```
核心：太乙金华宗旨（回光守窍）
    ↓
配合：灵宝毕法（匹配阴阳、聚散水火）
    ↓
进阶：凝神入气穴、逍遥诀
```

## 二、工作日方案（周一至周五）

### 2.1 晨间（6:00 - 7:00）

| 时间 | 内容 | 时长 | 说明 |
|------|------|------|------|
| 6:00-6:10 | **卧式调息** | 10分钟 | 躺床，多入少出呼吸，唤醒身体 |
| 6:10-6:25 | 洗漱准备 | 15分钟 | 正常洗漱 |
| 6:25-6:45 | **晨间静坐** | 20分钟 | 回光守窍：垂帘、注想天心 |
| 6:45-7:00 | 早餐、出门准备 | 15分钟 | |

**晨间要点**：
- 起床后先不看手机，直接调息
- 20分钟静坐是"定海神针"，质量比时长重要
- 若某天时间紧，至少保证10分钟静坐

### 2.2 通勤路上（地铁/公交）

| 场景 | 方法 | 说明 |
|------|------|------|
| 等车/等地铁 | **垂帘守窍** | 眼睛半垂，意注天心，不观外物 |
| 地铁有座位 | **回光 + 调息** | 闭目回光，配合多入少出呼吸 |
| 地铁站立 | **守中** | 意守丹田，保持中正，不随车晃动 |
| 公交车上 | **回光** | 坐靠窗，半垂帘，回光 |

**通勤要点**：
- 通勤时间是**隐藏的修炼黄金时间**
- 不刷手机、不听音乐，把通勤变成修炼
- 嘈杂环境是练"不随境转"的好机会

### 2.3 工作期间

| 时间 | 内容 | 时长 | 说明 |
|------|------|------|------|
| 工间休息 | **微型回光** | 1-2分钟 | 去洗手间或茶水间，闭目回光 |
| 午休 | **回光 + 午睡** | 15-20分钟 | 先回光5分钟，再午休 |
| 开会/等待 | **守中** | 随时 | 意守丹田，保持内心平静 |

**工作要点**：
- 不追求长时间，贵在**频繁短时**
- 每次工间1-2分钟，一天积累效果可观
- 保持"不欣不戚，明明白白"的心态

### 2.4 晚间（下班后 - 22:30）

| 时间 | 内容 | 时长 | 说明 |
|------|------|------|------|
| 下班通勤 | **回光** | 同早上 | 同早上的通勤方法 |
| 到家-20:30 | 晚餐、家务、陪伴家人 | | 正常生活，不废弃正业 |
| 20:30-21:00 | **散步或八段锦** | 20-30分钟 | 小区内散步调息，或做八段锦 |
| 21:00-21:30 | **晚间静坐** | 20-30分钟 | 回光守窍，比晨间更深入 |
| 21:30-21:45 | **修炼日记** | 10-15分钟 | 记录当天修炼体验 |
| 21:45-22:30 | 洗漱、放松、入睡 | | |

**晚间要点**：
- 散步/八段锦是**动静结合**的关键
- 晚间静坐质量往往比晨间好
- 修炼日记是进步的阶梯

## 九、注意事项

### 9.1 关于环境

| 问题 | 建议 |
|------|------|
| 家里空间小 | 不需要大空间，一张椅子或床边即可静坐 |
| 家人干扰 | 与家人沟通，争取早晚各20-30分钟不被打扰 |
| 小区噪音 | 噪音是练"不随境转"的好机会，不必刻意追求安静 |

### 9.2 关于身体

| 问题 | 建议 |
|------|------|
| 43岁身体机能 | 循序渐进，不可急于求成 |
| 久坐办公 | 晚间必须配合散步或八段锦 |
| 疲劳时 | 疲劳时只做调息，不勉强静坐 |

### 9.3 关于心态

| 问题 | 建议 |
|------|------|
| 工作压力大 | 工作中保持"守中"，本身就是修炼 |
| 进度慢 | 不比较、不焦虑，绵绵密密 |
| 间断 | 偶尔间断不要自责，第二天继续即可 |

### 9.4 关于证验

| 阶段 | 预期证验 | 说明 |
|------|----------|------|
| 入门期 | 心渐静、杂念减少 | 正常现象 |
| 筑基期 | 丹田温暖、身体发热 | 活子时体验 |
| 深入期 | 口中津液增多 | 玉液基础 |
