## 一、理论简述

第三门"交媾龙虎"是小乘安乐延年法的核心功法，也是从前两门向第四门过渡的关键环节。

**核心思想**：
- 肾中生气，气中有真水（真龙）
- 心中生液，液中有真气（真虎）
- 当肾气到心，心气相合，太极生液
- 当心液到肾，肾水相合，太极生气
- 气液互相交合相恋而下，名曰"交媾龙虎"

> "若以火候无差，而抽添合宜，三百日养就真胎而成大药，炼质焚身，朝元超脱之本也。"

## 二、核心原理

### 天地模型

《灵宝毕法》以天地阴阳升降之理喻人身：

| 天地 | 人身 |
|------|------|
| 阳升到天，太极而生阴 | 肾气到心，肾气与心气相合，太极生液 |
| 阴降到地，太极而生阳 | 心液到肾，心液与肾水相合，太极生气 |
| 窈冥抱阳而下降 | 液中有真气，真水恋气 |
| 恍惚负阴而上升 | 气中有真水，真气恋液 |

### 太极生液与太极生气

```
【太极生液】
肾气（坎卦）→ 上升 → 到心（离卦）
                    ↓
              肾气与心气相合
                    ↓
               太极生液
                    ↓
              液中有真气（真虎）

【太极生气】
心液（离卦）→ 下降 → 到肾（坎卦）
                    ↓
              心液与肾水相合
                    ↓
               太极生气
                    ↓
              气中有真水（真龙）
```

### "交媾"的含义

不是简单的阴阳相加，而是**气液互相交合相恋**：

> "本不相合，盖液中有真气，气中有真水，互相交合相恋而下，名曰交媾龙虎。"

**关键机制**：
- 液中有真气 → 真虎（心中的真阳）
- 气中有真水 → 真龙（肾中的真阴）
- 真气恋液，真水恋气 → 互相交合相恋

## 三、真龙真虎详解

### 什么是真龙真虎

| 名称 | 来源 | 本质 | 卦象 |
|------|------|------|------|
| **真龙** | 肾中生气 | 气中有真水 | 坎卦（☵）中阳 |
| **真虎** | 心中生液 | 液中有真气 | 离卦（☲）中阴 |

### 真龙真虎的比喻

| 比喻 | 真龙 | 真虎 |
|------|------|------|
| 卦象 | 坎水中的阳爻 | 离火中的阴爻 |
| 性质 | 阳中之阴 | 阴中之阳 |
| 来源 | 肾气上升 | 心液下降 |
| 特点 | 气中有真水 | 液中有真气 |

### 为什么叫"龙虎"

在丹道术语中：
- **龙**常指阳气、元神、性
- **虎**常指阴气、元精、命

但《灵宝毕法》此处特指：
- **真龙** = 肾中真阳（气中有真水）
- **真虎** = 心中真阴（液中有真气）

这是一种"互藏"关系——阳中有阴，阴中有阳。

### 核心时辰：子午二时

| 时辰 | 卦象 | 状态 | 修炼内容 |
|------|------|------|----------|
| **子时**（23:00-1:00） | 坎卦 | 肾中气生 | 心液到肾，太极生气 |
| **午时**（11:00-13:00） | 离卦 | 心中液生 | 肾气到心，太极生液 |

### 为什么选择子午时

| 时辰 | 天地对应 | 人身对应 |
|------|----------|----------|
| 子时 | 冬至，阴极阳生 | 肾中气生，一阳初生 |
| 午时 | 夏至，阳极阴生 | 心中液生，一阴初生 |

**关键**：
- 子时：心液下降，与肾水相合，太极生气
- 午时：肾气上升，与心气相合，太极生液

### 修炼时机

> "此恐泄元气而走真水于身外也。气散难生液，液少而无真气，气水不交，安成大药？"

**适用人群**：
- 元气未损、肾气充足者：可直接修炼
- 元气有损、肾气不足者：需先修炼第一、二门补亏

**补亏方法**：
> "当此年中用月，以冬至为始；日中用时，以离卦为期。或以晚年奉道，根源不固，自度虚损而气不足之后，十年之损，一年用功补之，名曰采补还丹。"

## 五、修炼方法

### 总体原则

> "当离卦肾气到心，神识内定，鼻息少入迟出，绵绵若存，而津满口勿吐勿咽，自然肾气与心气相合，太极生液。"

**核心原则**：
1. 神识内定——心神安定，不随境转
2. 鼻息少入迟出——呼吸轻缓细长
3. 绵绵若存——呼吸若有若无
4. 津满口勿吐勿咽——津液满口时，不吐不咽，自然相合

### 修炼步骤概览

```
第一步：择时
  ├── 午时（11:00-13:00）：肾气到心，太极生液
  └── 子时（23:00-1:00）：心液到肾，太极生气

第二步：入坐
  └── 静坐，神识内定，鼻息少入迟出，绵绵若存

第三步：等待
  └── 津满口，勿吐勿咽，自然肾气与心气相合

第四步：交媾
  └── 太极生液/生气，气液互相交合相恋而下

第五步：温养
  └── 静静温养，不可执着
```

## 六、具体步骤详解

### 午时修炼（肾气到心，太极生液）

#### 第一步：择时入坐

```
1. 午时（11:00-13:00），选择安静处
2. 端坐或盘坐，脊柱自然挺直
3. 轻轻闭目，舌抵上腭
4. 全身放松，从头顶到脚底逐一放松
```

#### 第二步：调息安神

```
1. 鼻息少入迟出——吸气少，呼气长而慢
2. 绵绵若存——呼吸若有若无，极轻极微
3. 神识内定——心神安定，不随杂念流转
4. 意念轻轻关注心肾之间
```

#### 第三步：等待津液

```
1. 静候口中津液自生
2. 津液满口时，勿吐勿咽
3. 此时肾气自然与心气相合
4. 太极生液——液中有真气（真虎）
```

#### 第四步：龙虎交媾

```
1. 液中有真气，气中有真水
2. 真气恋液，真水恋气
3. 互相交合相恋而下
4. 名曰交媾龙虎
```

### 子时修炼（心液到肾，太极生气）

#### 操作要点

```
1. 子时（23:00-1:00），入静坐
2. 同样鼻息少入迟出，绵绵若存
3. 心液自然下降，与肾水相合
4. 太极生气——气中有真水（真龙）
5. 龙虎交媾，气液相恋
```

### 关键要点

| 要点 | 说明 |
|------|------|
| **神识内定** | 心神安定，不随境转，这是交媾的前提 |
| **鼻息少入迟出** | 吸气少，呼气长而慢，减少元气耗散 |
| **绵绵若存** | 呼吸若有若无，进入极静状态 |
| **津满口勿吐勿咽** | 津液满口时，不人为吐咽，让其自然相合 |
| **自然相合** | 不刻意追求，让肾气与心气自然交合 |

## 七、火候与抽添

### 什么是火候

> "若以火候无差，而抽添合宜，三百日养就真胎而成大药。"

| 术语 | 含义 |
|------|------|
| **火候** | 意念和呼吸的运用时机与程度 |
| **抽添** | 抽减阳气（抽铅），添入阴气（添汞），或反之 |
| **无差** | 时机把握准确，不急不缓 |
| **合宜** | 程度恰到好处，不过不及 |

### 火候的关键

| 方面 | 要求 |
|------|------|
| **时机** | 子午二时，肾气到心或心液到肾时 |
| **呼吸** | 少入迟出，绵绵若存 |
| **意念** | 神识内定，不执着 |
| **津液** | 满口勿吐勿咽，自然相合 |

### 抽添的含义

在交媾龙虎阶段，抽添主要指：
- **抽**：抽减过盛之气或液
- **添**：添补不足之气或液
- **目的**：使气液平衡，龙虎均衡

## 十、常见错误与纠正

### 呼吸方面

| 错误 | 表现 | 原因 | 纠正方法 |
|------|------|------|----------|
| **呼吸急促** | 心烦意乱，无法入静 | 急于求成，心神不宁 | 放慢呼吸，先自然呼吸数分钟 |
| **憋气过度** | 胸闷、头晕 | 强行控制呼吸 | 鼻息少入迟出，不可憋气 |
| **呼吸散乱** | 杂念纷飞，坐不住 | 心神未定 | 先修第一门，待心静再修第三门 |

### 意念方面

| 错误 | 表现 | 原因 | 纠正方法 |
|------|------|------|----------|
| **神识不定** | 杂念纷飞，无法集中 | 炼己功夫不足 | 加强第一门"收心炼己" |
| **追求津液** | 刻意等待，反而无津 | 意念过重 | 放下期待，自然等待 |

### 时间方面

## 十一、疑难解答

**Q1：为什么要"津满口勿吐勿咽"？**

A：这是交媾龙虎的关键。当津液满口时，不人为吐咽，让肾气与心气自然相合，太极自然生液。如果人为吐咽，就破坏了自然交合的过程。

**Q2：子时修炼会不会影响睡眠？**

A：子时（23:00-1:00）是最佳修炼时机，但确实可能影响睡眠。建议：
- 初学者可先练午时，子时保证睡眠
- 有一定基础后，可在子时前入睡，23:00左右醒来修炼，然后再睡
- 或选择子时初（23:00左右）修炼，不等到深更半夜

**Q3："神光暗中自见双目"是什么？**

A：这是修炼有成的表现之一。闭目静坐时，眼前自然出现光明，如闪电、如圆月。这是体内阳气充盈、精气神充足的表现，不可刻意追求。

**Q4：如果肾气不足，能否直接修炼第三门？**

A：原文明确指出："气散难生液，液少而无真气，气水不交，安成大药？"如果元气不足，应先修炼第一、二门补亏，待元气充足后再修第三门。

**Q5："十年之损，一年用功补之"是什么意思？**

A：这是说如果年老或身体亏损严重，需要先用一年时间补足亏损（采补还丹），然后再正式修炼交媾龙虎。

**Q6：午时和子时都要练吗？**

A：理想情况下，子午二时都练。但如果条件不允许，至少练午时（相对容易）。子时可根据个人情况调整。
