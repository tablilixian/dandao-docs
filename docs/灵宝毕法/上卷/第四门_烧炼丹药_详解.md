## 一、理论简述

第四门"烧炼丹药"是小乘安乐延年法的最后一门，也是前三门的综合与升华。

**核心思想**：
- 前三门（匹配阴阳、聚散水火、交媾龙虎）已完成筑基基础
- 第四门开始正式"采药"——采天地阴阳之气
- 通过"勒阳关"和"烧炼"，使气液造化，凝结金丹
- 最终使"形若弹圆，色同朱橘，永镇丹田"

> "谨节用功，加添依时三百。数足之后，方行还丹炼形之法。"

> "三百日后行持，至离卦罢采药，坤卦罢勒阳关，即行玉液还丹之道。"

## 二、核心原理

### 天地模型

《灵宝毕法》以天地阴阳造化之理喻金丹生成：

| 天地 | 人身 |
|------|------|
| 天地相交，阴阳合和 | 心肾相交，气液相合 |
| 积阴成霜雪，积阳成云雾 | 积气成液，积液化精 |
| 霜雪雨露能润草木 | 津液精气能养形体 |
| 金石成形 | 气液造化，凝结金丹 |

### 阴阳相成之理

> "阴不得阳不生，阳不得阴不成。"

| 阴 | 阳 | 相成 |
|------|------|------|
| 地 | 天 | 天气下降，地气上升 |
| 月 | 日 | 月受日之光 |
| 水 | 火 | 水中有火，火中有水 |
| 液 | 气 | 气中有液，液中有气 |

### 金丹的本质

> "气液造化，时变而为精，精变而为珠，珠变而为汞，汞变而为砂，砂变而为金，乃曰金丹。"

**金丹生成序列**：
```
气 → 液 → 精 → 珠 → 汞 → 砂 → 金 → 金丹
```

## 六、具体步骤详解

### 第一步：离卦采药（午时）

#### 原理

> "离卦采药"——午时为离卦，此时肾气到心，心肾相交，宜采药。

#### 操作方法

```
1. 午时（11:00-13:00），入静室端坐
2. 轻轻闭目，舌抵上腭
3. 神识内定，心息相依
4. 鼻息绵绵，若有若无
5. 采天地阴阳之气，归于丹田
```

#### 要点

| 要点 | 说明 |
|------|------|
| **采药** | 采天地阴阳之气，非采外在药物 |
| **归于丹田** | 意念引导气入下丹田 |
| **神识内定** | 心神安定，不随境转 |

### 第二步：坤卦勒阳关

#### 原理

> "坤卦勒阳关"——坤卦时，固摄真水，不令气上行外泄。

#### "勒阳关"详解

**什么是"阳关"**：
- 阳关 = 阳气外泄的关口
- 在人体中，主要指下丹田至命门区域
- 阳气外泄的主要通道

**什么是"勒"**：
- 勒 = 收紧、固摄、约束
- 如勒马缰，使马不狂奔
- 使气不下行外泄，固摄于丹田

#### 操作方法

```
1. 坤卦时（13:00-17:00）
2. 使气不上行，以固真水
3. 经脾宫，随呼吸搬运于命府黄庭之中
4. 觉热太甚，微微轻勒
5. 腹脐未热，渐渐紧勒
6. 守常任意，放志以满乾坤
```

#### 勒阳关的三个层次

| 层次 | 状态 | 操作 |
|------|------|------|
| **初层** | 腹脐未热 | 渐渐紧勒 |
| **中层** | 觉热太甚 | 微微轻勒 |
| **高层** | 热满黄庭 | 守常任意，放志以满乾坤 |

### 第三步：乾卦烧炼

#### 原理

> "乾卦烧炼"——乾卦时，温养金丹，运化精微。

#### 操作方法

```
1. 乾卦时（19:00-23:00）
2. 使金丹温养于丹田
3. 气液造化，精微运化
4. 绵绵若存，温温不绝
5. 金丹渐凝，色同朱橘
```

#### 要点

| 要点 | 说明 |
|------|------|

## 十二、疑难解答

**Q1：什么是"勒阳关"？具体怎么操作？**

A：勒阳关就是固摄真水，不令气上行外泄。具体操作：
1. 感觉腹脐发热时，轻轻收紧（轻勒）
2. 感觉不到热时，渐渐紧勒
3. 热满黄庭后，守常任意，放志运化
4. 关键是"勒"的程度——以舒适为度，不可过紧或过松

**Q2：为什么要"春冬多采少炼，秋夏少采多炼"？**

A：春冬阳气初生，宜多采以补养；秋夏阳气盛极，宜多炼以化精。这是顺应四时阴阳消长的道理。

**Q3："形若弹圆，色同朱橘"是什么感觉？**

A：这是金丹成就的表现。"形若弹圆"是指丹田部位感觉有一个形如弹丸的东西；"色同朱橘"是指该部位色泽红润。出现这些感觉时，说明金丹已初步凝成。

**Q4：第四门练成后是什么成就？**

A：原文说"永镇丹田，而作陆地神仙"——金丹永驻丹田，成为超越常人的陆地神仙，延年益寿。但这是小乘成就，还需继续修炼中乘、上乘功法，才能成就天仙。

**Q5："玉液还丹"是什么意思？**

A：第四门完成后，进入"玉液还丹"阶段。玉液是高质量的津液，还丹是使金丹更加纯粹。离卦罢采药、坤卦罢勒阳关后，就进入这个阶段。
