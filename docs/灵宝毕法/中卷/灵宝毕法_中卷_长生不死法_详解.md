## 一、中卷概述

### 三乘体系

《灵宝毕法》将内丹修炼分为三乘：

| 乘次 | 名称 | 内容 | 成就 |
|------|------|------|------|
| **上卷** | 小乘安乐延年法 | 四门（匹配阴阳、聚散水火、交媾龙虎、烧炼丹药） | 人仙、陆地神仙 |
| **中卷** | 中乘长生不死法 | 三门（肘后飞金晶、玉液还丹、金液还丹） | 地仙、长生不死 |
| **下卷** | 大乘超凡入圣法 | 三门（朝元炼气、内观交换、超脱分形） | 天仙、超凡入圣 |

### 中乘核心目标

> "三百日后行持，至离卦罢采药，坤卦罢勒阳关，即行玉液还丹之道。"

**小乘成就**：凝结金丹，永镇丹田（人仙）
**中乘成就**：玉液还丹、金液还丹，长生不死（地仙）

### 中乘三门关系

```
第五门：肘后飞金晶（三百日）
    ↓ 泥丸充实，返老还童
第六门：玉液还丹
    ↓ 内丹之材，玉液炼形
第七门：金液还丹
    ↓ 金丹成就，长生不死
```

## 二、第五门：肘后飞金晶

### （一）原文详解

#### 1. 总纲

> **原文**："肘后飞金晶第五"

> **原文**："正一阳时，坎卦行持，乃曰肘后飞金晶。"

> **原文**："自丑行之，至寅终而可止，乃曰肘后飞金晶，又曰抽铅，使肾气生肝气也。"

**直解**：
- **"肘后"**：指脊背后方，督脉路径
- **"飞金晶"**：将肾中真阳（金晶）从尾闾飞升至泥丸
- **"抽铅"**：抽取肾中真铅（肾气），生肝气
- **"正一阳时"**：子时之后，阳气初生之时
- **"坎卦"**：子时（23:00-1:00），一阳初生

#### 2. 三关原文

> **原文**："背后尾闾穴曰下关，夹脊曰中关，脑后曰上关。"

> **原文**："始炼形者，先要降下腰腹，蹲下腹肚，升身前出胸而微偃头于后，后闭夹脊双关，肘后微扇一二，伸腰自尾闾穴如火相似，自腰而起，拥在夹脊，慎勿开关。"

> **原文**："即时甚热气壮，渐次开夹脊关而放气过关，仍仰面脑后紧偃，以闭上关，慎勿开之。即觉热极气壮，渐次入顶，以补泥丸髓海。"

#### 3. 三百日分阶段原文

> **原文**："始一百，飞金晶入脑，三关一撞，直入上宫泥丸。自坎卦为始，至艮卦方止。"

> **原文**："又一百之后，肘后飞金晶，自坎卦至震卦方止。"

> **原文**："如此又一百足，泥丸充实，返老还童，不类常人。"

### （二）三关详解

#### 1. 三关位置与特性

| 关名 | 位置 | 别名 | 特性 |
|------|------|------|------|
| **下关（尾闾关）** | 脊椎尾部，尻脊上第三节 | 长强穴、三岔路、河车路、禁门 | 气的起点，最难突破 |
| **中关（夹脊关）** | 脊柱中段，内肾相对处 | 双关、辘轳关 | 气的枢纽，对应心 |
| **上关（玉枕关）** | 脑后，枕骨下方 | 天柱关、铁壁 | 最后一关，入脑门户 |

#### 2. 脊骨结构详解

> **原文**："且人身脊骨二十四节：自下而上三节，与内肾相对；自上而下三节，名曰'天柱'；天柱之上，名曰'玉京'。天柱之下，内肾相对，尾闾穴之上，共十八节，其中曰'双关'。上九下九，当定。"

**脊骨结构**：
```
玉京（泥丸宫）
    ↑
天柱（上三节）← 玉枕关所在
    ↑
双关（中十八节，上九下九）← 夹脊关所在
    ↑
内肾相对处（下三节）
    ↑
尾闾穴 ← 尾闾关所在
```

#### 3. 三关通关方法

**（1）尾闾关（下关）**

| 项目 | 内容 |
|------|------|
| **开关方法** | 下腰自腹渐渐举腰，升身而凸胸偃脊 |
| **操作要点** | 蹲下腹肚，使气下沉；然后举腰升身 |
| **感觉** | 尾闾穴如火相似，自腰而起 |
| **注意事项** | 气热盛后方可过关，不可强求 |

**（2）夹脊关（中关）**

| 项目 | 内容 |
|------|------|
| **开关节奏** | 先闭夹脊双关，待热气壮后渐次打开 |
| **操作要点** | 凸胸偃脊，以开中关；肩部放松，塌肩下坠 |
| **感觉** | 热气拥在夹脊，甚热气壮 |
| **注意事项** | 慎勿过早开关，待气壮后渐次开放 |

**（3）玉枕关（上关）**

| 项目 | 内容 |
|------|------|
| **开关节奏** | 仰面脑后紧偃，紧闭上关，待热极气壮后渐次入顶 |
| **操作要点** | 平坐昂头，以开上关；头部略后仰，下颚微收 |
| **感觉** | 热极气壮，渐次入顶 |
| **注意事项** | 现代人颈椎多有劳损，通关难度较大，需耐心 |

#### 4. 三关一撞法

> **原文**："下关开后气热盛上关之下方，可举腰升身正坐，一撞三关都过，补脑髓，自然面红骨健，肌白身轻，是名返老还童，长生不死之法。"

**"一撞三关"**：三关依次打开后，真气可一撞而过，直入泥丸。

**操作要点**：
1. 下关开后，气热盛于上关之下
2. 举腰升身正坐
3. 一撞三关都过
4. 补脑髓

### （三）修炼方法详解

#### 1. 时辰与卦象

| 项目 | 内容 |
|------|------|
| **时辰** | 丑时至寅时（1:00-5:00） |
| **起始卦** | 坎卦（子时，23:00-1:00） |
| **终止卦** | 艮卦→震卦→巽卦（分阶段） |

**卦象对应时辰**：
- 坎卦：子时（23:00-1:00）
- 艮卦：丑时（1:00-3:00）
- 震卦：卯时（5:00-7:00）
- 巽卦：辰时（7:00-9:00）

#### 2. 具体步骤

**准备阶段**：
```
1. 静室中，切禁风日
2. 遥焚香，密启三清上圣
3. 披衣握固，正坐盘膝
```

**修炼过程**：
```
第一步：蹲下腹肚
  - 腹部内收，气沉丹田
  - 使肾气凝聚于尾闾

第二步：升身前出胸而微偃头于后
  - 身体微微前倾，胸部前出
  - 头微微后仰

第三步：后闭夹脊双关
  - 夹脊穴紧闭
  - 肘后微扇一二（两肘微微扇动）

第四步：伸腰自尾闾穴如火相似
  - 伸腰，使气从尾闾升起
  - 感觉如火一般温热

第五步：自腰而起，拥在夹脊
  - 热气从腰升起
  - 聚集于夹脊关

第六步：慎勿开关
  - 不可过早打开夹脊关
  - 待热气壮盛

第七步：渐次开夹脊关而放气过关
  - 热气壮盛后，逐渐打开夹脊关
  - 气过关隘

第八步：仰面脑后紧偃，以闭上关
  - 头后仰，紧闭玉枕关
  - 慎勿开之

第九步：渐次入顶，以补泥丸髓海
  - 热极气壮后，气渐入顶
  - 补益脑髓
```

#### 3. 握固法

**握固**：双手握拳，固摄精气

**具体方法**：
- 大拇指掐于无名指根部
- 其余四指握拳包住大拇指
- 双手置于膝上或腹前

**作用**：
- 固摄精气，防止外泄
- 助气凝聚于丹田

### （六）常见错误与纠正

#### 错误一：急于通关

| 项目 | 内容 |
|------|------|
| **错误表现** | 气未壮盛即强行通关，导致气机紊乱 |
| **后果** | 头痛、胸闷、气滞 |
| **纠正方法** | 待气热盛后再过关，"慎勿开关" |

#### 错误二：姿势不当

| 项目 | 内容 |
|------|------|
| **错误表现** | 脊柱不正，头颈僵硬 |
| **后果** | 气机受阻，通关困难 |
| **纠正方法** | 调整姿势，脊柱正直，颈部放松 |

#### 错误三：意念过重

| 项目 | 内容 |
|------|------|
| **错误表现** | 用意过猛，强行导引 |
| **后果** | 气机逆乱，头晕目眩 |
| **纠正方法** | 意念轻柔，"勿忘勿助" |

#### 错误四：玉枕关难通

| 项目 | 内容 |
|------|------|
| **错误表现** | 气到玉枕关停滞不前 |
| **原因** | 现代人颈椎多有劳损，玉枕关最难通过 |
| **纠正方法** | 头部略后仰，下颚微收，调整颈部曲度；耐心等待，不可强求 |

#### 错误五：修炼时辰不当

| 项目 | 内容 |
|------|------|
| **错误表现** | 不按卦象时辰修炼 |
| **后果** | 效果不佳，气机不调 |
| **纠正方法** | 严格按照坎卦至艮/震/巽卦的时辰修炼 |

## 三、第六门：玉液还丹

### （一）原文详解

#### 1. 总纲

> **原文**："玉液还丹第六"

> **原文**："离卦采药，用法依时内观，转加精细。"

> **原文**："薰蒸于肺，而得肺液下降，包含真气，曰得黍米之大，而入黄庭。方曰内丹之材，百无差，药力全。"

**直解**：
- **"玉液"**：肺液下降，甘甜如玉，包含真气
- **"还丹"**：将玉液还归丹田，凝结成丹
- **"离卦采药"**：午时（11:00-13:00）采药
- **"薰蒸于肺"**：心火薰蒸肺金，产生肺液
- **"黍米之大"**：丹形如黍米大小
- **"黄庭"**：中丹田，心下脐上

#### 2. 玉液炼形

> **原文**："玉液炼形者，以其肺液还于中田，以入下田，而曰玉液还丹。"

**直解**：
- **"玉液炼形"**：用玉液炼化形体
- **路径**：肺液 → 中田（黄庭）→ 下田（丹田）

### （二）理论详解

#### 1. 玉液的生成

**生成过程**：
```
心火（离卦）
    ↓ 薰蒸
肺金
    ↓ 生成
肺液（玉液）
    ↓ 包含真气
玉液还丹
```

**五行关系**：
- 心属火，肺属金
- 火克金，心火薰蒸肺金
- 肺液下降，甘甜如玉

#### 2. 玉液还丹的路径

| 阶段 | 路径 | 说明 |
|------|------|------|
| **第一步** | 心火薰蒸肺金 | 离卦采药 |
